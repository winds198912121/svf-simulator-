📊 データ編集ガイド

SVF Simulator - データの変更方法

🎯 方法1: 直接編集（一番簡単）

ステップ1: 下部の「データソース」タブをクリック
ステップ2: JSONエディタで数値や文字を直接変更
ステップ3: 「✓ 検証」ボタンで確認
ステップ4: 「プレビュー」タブで結果を確認
例: 発注番号を変更 
変更前: "po_number": "PO-2026-001"
変更後: "po_number": "PO-2026-999"

📝 よく変更する項目

項目 JSONのパス 例
発注番号 header.po_number "PO-2026-999"
日付 header.po_date "2026-12-31"
供給者名 header.vendor_name "新しい会社名"
合計金額 summary.total 999000

🔢 数値の変更

金額を変更する例:

{
  "summary": {
    "subtotal": 250000,  ← ここを変更
    "tax_amount": 25000,  ← ここを変更
    "total": 275000       ← ここを変更
  }
}
💡 ヒント: 数値は引用符なし（"" なし）で書きます
✅ 正しい: "total": 275000
❌ 間違い: "total": "275000"

📋 明細行の追加/削除

明細行を追加:

"items": [
  {
    "line_no": "001",
    "material_name": "部品A",
    "quantity": 100,
    "unit_price": 1500,
    "amount": 150000
  },
  ← ここにカンマ(,)を追加
  {
    "line_no": "002",
    "material_name": "部品B",
    "quantity": 50,
    "unit_price": 2000,
    "amount": 100000
  }  ← 新しい行を追加
]
⚠️ 注意:
  • 最後の項目の後にはカンマ(,)を付けない
  • 項目と項目の間にはカンマ(,)が必要

✨ 完全なカスタムデータ例

あなた専用のデータ:

{
  "header": {
    "po_number": "あなたの注文番号",
    "po_date": "2026-11-15",
    "vendor_name": "あなたの会社名",
    "vendor_address": "あなたの住所"
  },
  "items": [
    {
      "line_no": "001",
      "material_name": "あなたの商品名",
      "quantity": 123,
      "unit_price": 4500,
      "amount": 553500
    }
  ],
  "summary": {
    "subtotal": 553500,
    "tax_amount": 55350,
    "total": 608850
  }
}

🔍 エラーチェック

よくあるエラー:

エラー 原因 解決法
Unexpected token カンマの位置が間違い 最後の項目のカンマを削除
Unexpected end 括弧が閉じていない { } [ ] を確認
Invalid character 全角文字を使用 半角文字に変更
💡 ヒント: 変更後は必ず「✓ 検証」ボタンをクリック！

🎬 実践ワークフロー

1. テンプレートを読込（ZPOF001 または Invoice）
2. データソースタブ → サンプル読込
3. 数値や文字を変更
例: "po_number": "PO-2026-001" → "PO-2026-999"
4. 「✓ 検証」をクリック
5. プレビュータブで確認
6. 満足したら「💾 保存」
